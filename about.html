// about xorio

Software craftsmanship taken to perfection.

Xorio is a Rust & STEM open-source collective. We craft innovative solutions in Rust and other safe languages — Kotlin, Go, Python, Flutter and Java — with collaboration and transparency at the core, focused on high-performance systems, robust web services and secure applications.

what we do

High-performance systems

Systems software in Rust — filesystems, distributed storage, encryption and OS-level tooling built for speed and safety.

Robust web services

Backends and APIs with gRPC, REST, tonic and serverless stacks — engineered to stay up and stay fast.

Secure applications

Security-first software: encrypted filesystems, cryptography, zeroized memory and safe-by-construction design.

Open-source collaboration

Everything is built in the open — public repos, public roadmaps, and contributors welcomed at every level.

flagship work

Our best-known project is rencfs — an encrypted filesystem that mounts with FUSE, named Rust crate of the week in August 2024. Around it grew a whole family: SyncOxiders for cloud file sync and encryption, rfs for distributed filesystems, desktop and daemon frontends, Python bindings and more — 30+ projects, all listed in the gallery.

grow — learning & community

Learn

We organize several free and open-source courses because we want to be the mentors we didn't have — it's also one way we give back to the community. Join Discord and choose the courses you're interested in — details in the #courses channel.

Mentor

If you want to be a mentor and help others grow, you're among the right people. Join Discord — the #i-am-a-mentor channel explains how to get started.

Talks & coding challenges

Periodic in-person and online talks and coding challenges keep you up to date with the latest tech and sharpen problem-solving. Announced in channels like #coding-challenge; events are organized on Meetup (Star Tech RD Reloaded).

Many of our experiments have no contributors yet — you could be the first. If you want to ship a feature, mentor, or just learn in the open, there's a seat for you.
